## 🚀 Features

### 🎨 Advanced Visual Effects
- **Neural Network Background**: Dynamic nodes with energy propagation and quantum particles
- **3D Floating Geometry**: Wireframe shapes (spheres, toruses, octahedrons) floating in space
- **Holographic Cards**: RGB split effects, chromatic aberration, and scanlines
- **Advanced Cursor**: Particle trail system with interactive mouse effects
- **Glass Morphism**: Enhanced backdrop blur with multi-layer gradients

### ⚡ Interactive Sections
- **Hero Section**: Protocol status, system info, animated text effects, dual CTAs
- **Resource Allocation Matrix**: Animated metrics, holographic cards, terminal-style lists
- **Founder's Arsenal**: 3D rotating sphere with premium tools, ROI metrics
- **Neural Network**: Orbital builder nodes with energy connections
- **System Enhancements**: Animated icons, progress bars, status indicators
- **Neural Hub Access**: Holographic plan cards, animated amenities
- **Final Transmission**: Terminal simulation, multi-gradient CTA

### 🎯 Modern UX Patterns
- Scroll-based reveals and parallax effects
- Magnetic button interactions
- 3D card tilt on mouse movement
- Fluid text animations (decode, glitch, typewriter, morph)
- CountUp animated metrics
- Status indicators with pulsing dots
- Terminal text auto-typing

## 🛠️ Tech Stack

- **Frontend**: React 19 with TypeScript
- **Build Tool**: Vite 6.2
- **Styling**: Tailwind CSS + Custom CSS Variables
- **Animations**: Framer Motion 11
- **3D Graphics**: Three.js 0.160 + React Three Fiber
- **3D Helpers**: React Three Drei
- **Form Handling**: Formspree
- **SEO**: React Helmet Async

## 📦 Installation & Setup

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Local Development

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd hackhouse
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```

4. **Open your browser**

   Navigate to `http://localhost:5173` to view the application.

## 🏗️ Build & Deployment

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
